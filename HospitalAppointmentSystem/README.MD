# Hospital Appointment Management System

## Project Description
A Core Java project to manage hospital patients, doctors and appointments.

## Features
- Register patients
- Add doctors
- Book and cancel appointments
- View doctor schedules
- View patient history
- Generate hospital reports
- Save data using serialization

## Technologies
- Core Java
- OOP Concepts
- HashMap
- ArrayList
- Exception Handling
- File Handling
- Date and Time API
